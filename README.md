# VXN_Pay — система оплаты и Telegram-бот

Отдельный проект биллинга: нейтральный сайт, ЮKassa, Telegram-бот, автопродление пользователей Marzban.

## Как использовать с Cursor

1. Откройте папку `VXN_Pay` как **отдельный workspace** в Cursor (или добавьте её в контекст чата).
2. Перед началом работы прикрепите к промпту файл **[ПЛАН-ПРОЕКТА.md](./ПЛАН-ПРОЕКТА.md)**.
3. Укажите ИИ: «Реализуй по плану, фаза за фазой. VPN-инфраструктура уже на другом VPS — см. раздел „Связь с firstvds“.»

## Связь с VPN-проектом

| Проект | Папка / сервер | Назначение |
|--------|----------------|------------|
| VPN-инфраструктура | `firstvds/`, VPS `132.243.123.55` | Marzban, Xray, мониторинг |
| Биллинг | `VXN_Pay/`, **отдельный VPS** | Сайт, оплата, бот |

Два VPS связаны через **WireGuard**; биллинг вызывает Marzban API только по приватному туннелю.
