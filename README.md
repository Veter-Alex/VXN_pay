# VXN_Pay — сайт оплаты tip My Code

Биллинг и кабинеты для доступа к материалам с интеграцией **Marzban** (VPN-инфраструктура в соседнем проекте `VXN/`).

Публичная подача нейтральная (**tip My Code**): без упоминания VPN на сайте и в чеках.

## Роли и кабинеты

| Роль | URL | Возможности |
|------|-----|-------------|
| **admin** | `/admin` | Все пользователи, CRUD, категория тарифа, импорт из Marzban, назначение менеджеров, invite, сброс пароля |
| **manager** | `/manager` | Свои подопечные + свой аккаунт, создание пользователей (автоназначение себе), оплата за подопечных, invite, сброс пароля |
| **user** | `/cabinet` | Срок, subscription-ссылка, почта, оплата по своей категории, смена пароля через email |

Вход: **логин + пароль** на главной. Регистрации «с улицы» нет — только создание админом/менеджером и invite-ссылка.

## Invite-flow

1. Админ/менеджер создаёт пользователя (**логин** + **категория**; почта не обязательна).
2. Копирует ссылку-приглашение (иконка в таблице).
3. Пользователь по `/invite/{token}` задаёт **пароль** и **почту для восстановления**.
4. Если пароль уже задан — форма не показывается («ссылка уже использована»).
5. Сброс пароля в таблице → старый пароль не действует → нужно **новое** приглашение.

Правила логина Marzban: 3–32 символа, `a-z`, цифры, `_` только внутри.

## Связь с Marzban (VXN)

| Режим | `MARZBAN_BASE_URL` |
|-------|-------------------|
| Продакшен (WireGuard) | `http://10.10.0.1:8000` |
| Локальная разработка (SSH-туннель) | `http://host.docker.internal:18000` |

Пример туннеля (PowerShell):

```powershell
ssh -N -L 18000:127.0.0.1:8000 firstvds-jump1
```

Документация туннеля: [infra/wireguard/README.md](./infra/wireguard/README.md).

**Важно:** открытие `/admin` и `/manager` **не** синхронизирует всех с Marzban (данные из кэша БД). Live-запросы — при сохранении, импорте, оплате и (для ЛК) при устаревшем кэше.

## Быстрый старт (локально)

1. Скопировать `.env.example` → `.env`, заполнить `APP_SECRET_KEY`, bootstrap-admin, `MARZBAN_*`.
2. Поднять туннель к Marzban (см. выше), если нужна интеграция.
3. Запуск:

```powershell
docker compose up --build -d
```

API: http://localhost:8000  
Миграции: `alembic upgrade head` выполняется при старте контейнера `api`.

## Тарифы (seed)

| Категория | 30 дн. | 90 дн. |
|-----------|--------|--------|
| Льготная (`preferential`) | 75 ₽ | 225 ₽ |
| Коммерческая (`commercial`) | 500 ₽ | 1500 ₽ |

Категория задаётся админом; пользователь и менеджер платят по тарифам своей/подопечного категории.

## Безопасность

- Файл `.env` **не** коммитить (в `.gitignore`).
- В `.env.example` только плейсхолдеры.
- Приватные SSH-ключи (в т.ч. из `VXN/secure/ssh/`) **не** добавлять в git.
- `COOKIE_SECURE=true` и реальный SMTP — для продакшена.
