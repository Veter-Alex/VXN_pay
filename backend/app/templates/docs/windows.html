Настройка на Windows

  1. Скачайте приложение Hiddify для Windows.
  2. Установите и запустите программу.
  3. В личном кабинете скопируйте ссылку подключения.
  4. В Hiddify: «Добавить профиль» → вставьте ссылку → сохраните.
  5. Нажмите «Подключить».

При смене срока доступа нажмите «Обновить подписку» в приложении.
